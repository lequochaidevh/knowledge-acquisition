# Kitty command

### new Kitty in origin terminal
```sh
kitty > /dev/null 2>&1 &
```
### Split screen
```sh
Ctrl + Alt + V (or H)
```
### Move
```sh
Ctrl + H (J,K,L)
```
### Reload
```sh
Ctrl + Alt + F5
```

### Open kitty and RUN COMMAND: open image in terminal
```sh
kitty --hold sh -c "kitten icat ~/Desktop/_kitty"
```
