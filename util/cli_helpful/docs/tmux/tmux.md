# TMUX instructions

## Install tmux
```sh
sudo apt install tmux
```

### Start `tmux` in native terminal
```sh
tmux
# Press "Enter"
```

### Split creen
Horizontally:
```sh
Press Ctrl + B
Release all
Press "
```
Vertically:
```sh
Press Ctrl + B
Release all
Press %
```

### Exit
```sh
exit
# Press "Enter"
```

### Cursor Switching
```sh
Press Ctrl + B
Release all
Press any Arrow Key
# or Press Tab to jump the cursor to next split window region. 
```
